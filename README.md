# 27-Day Machine Learning Engineering Sprint

A practical, production-focused engineering sprint covering core ML math, data pipelines, applied machine learning, and modern Retrieval-Augmented Generation (RAG) systems.

---

## Sprint Overview

- Core Focus: Applied Linear Algebra, Scikit-Learn Pipelines, Vector Math, and End-to-End RAG Systems.
- Architecture: Modular codebase organized by weekly milestones.
- Code Standards: Clean documentation, type consistency, and conventional commits.
